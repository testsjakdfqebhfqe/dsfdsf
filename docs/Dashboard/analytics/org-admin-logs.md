# What are Admin Logs

This section of the web panel is available to Organization accounts, and provides an audit trail of all actions performed by admins within an organization. 

![](https://files.readme.io/7ce74265cb94dc3a4f0b38080a5c8e5786560933f318237935d18b63ceb7133e-image.png)

This is useful for compliance and internal troubleshooting.

## Search and Filter

The Admin logs can be filtered by:

* **Organization** - *Where* the action occurred 
* **Admin email** - *Who* performed the action
* **Action performed** - *What* specific action was performed 

You can also perform searches based on the associated metadata (device or services names, previous values, etc).
