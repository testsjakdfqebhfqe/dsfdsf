# What are Modes

![](https://files.readme.io/bd6221164c65892cc4811437e52d9194d036758ab05d68c60fd7eaec19276c8d-image.png)

The Ads & Trackers Fiilter has 3 district modes it can be operated in. These modes are:

* **Relaxed** - blocks only very common ads and tracking domains. If you prefer having few false positives and are OK with occasional ads loading, use this mode.  
* **Balanced** - More aggressive version of the Relaxed filter. Will block more domains, but still allows for very common tracking domains (like email links, and affiliate tracking links) to load. This mode is a recommended starting point. 
* **Strict** - Will block all known Ads & Tracker domains, regardless of it breaking some websites and services that force you to load trackers. Use this if you're OK with making bypass rules to work around these blocks.
