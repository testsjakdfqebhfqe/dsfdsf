# What is Safe Search

This feature allows you to enable Safe Search on all search engines that support it. Enabling it will prevent these search engines from showing NSFW content. Search engines that don't support this will be blocked. 

## How to Use it

Edit a Profile and click on **Profile Options**. Scroll down and toggle it on.
