# What is Restricted YouTube

This feature allows you to force YouTube into [restricted mode](https://support.google.com/youtube/answer/174084). This will hide all mature content and disable the comment section. 

## How to Use it

Edit a Profile and click on **Profile Options**. Scroll down and toggle it on.
