## DNS-over-HTTPS

![](https://files.readme.io/f7c047d-image.png)

1. Navigate to this [Online DNS Stamp calculator](https://dnscrypt.info/stamps/)
2. Select DNS-over-HTTPS
3. Enter `dns.controld.com`in the `Host name`section
4. Enter a `/`followed by your Resolver ID (which you can get by creating an Endpoint in the Control D Dashboard) in the `Path`section
5. Copy the stamp
6. Done!
