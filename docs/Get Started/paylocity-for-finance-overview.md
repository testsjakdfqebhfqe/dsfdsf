## Overview

Build integrations that connect Paylocity for Finance with ERP systems, reporting platforms, data warehouses, procurement tools, and other business applications.

The Paylocity for Finance API platform supports ERP integration, financial reporting, Guided Procurement, and event-driven workflows through webhooks.

<Callout icon="⚠️" theme="info">
  ### API Availability

  **ERP Integration and Financial Reporting APIs** are available through the Paylocity for Finance Early Access programme. Response fields, filters, validation rules, and behaviour may change before general availability.<br />**Guided Procurement APIs** are generally available on an **invite-only** basis. Access must be enabled for your company.
</Callout>

## What each API family supports

| API family              | What you can do                                                                                                                                                              |
| ----------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **ERP integration**     | Synchronise accounts, currencies, employees, subsidiaries, tags, and vendors; retrieve ledger and prepayment entries; and return ERP synchronisation results.                |
| **Financial reporting** | Retrieve subsidiaries, payment transactions, cards, expense reports, vendors, bills, and purchase orders for reporting and reconciliation, subject to resource availability. |
| **Guided Procurement**  | Retrieve procurement requests and milestones, upload supporting files, and approve or deny supported milestones.                                                             |

## Common Conventions

Paylocity for Finance APIs use the following common conventions unless an endpoint documents otherwise.

| Convention           | Value                                   |
| -------------------- | --------------------------------------- |
| Base URL             | `https://api.airbase.io`                |
| Protocol             | HTTPS                                   |
| API style            | REST                                    |
| Primary format       | JSON                                    |
| Authentication       | API token                               |
| Authorisation header | `Authorization: Token <your_api_token>` |
| API version          | `v1`                                    |
| Standard rate limit  | 500 requests per minute per company     |

## Example Request

```curl
curl --location 'https://api.airbase.io/v1/subsidiaries/' \
--header 'Accept: application/json' \
--header 'Authorization: Token <your access token>'
```

For access and token-generation instructions, see [Quickstart](doc:quickstart).

## Before you begin

To use the Paylocity for Finance APIs, you need:

- A Paylocity for Finance company account
- An API token generated by an administrator
- An HTTPS client for making API requests
- A publicly accessible HTTPS endpoint if the integration uses webhooks
- Access to an ERP sandbox or test environment when building an accounting integration

Additional access requirements depend on the API family:

- ERP Integration: Participation in the Paylocity for Finance Early Access programme
- Financial Reporting: Participation in Early Access and enablement of the applicable reporting resources
- Guided Procurement: An invitation and API enablement for your company

For API integration support or access assistance, contact [ab-api@paylocity.com](mailto:ab-api@paylocity.com).
