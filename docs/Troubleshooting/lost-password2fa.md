# Lost Password

If you have forgotten your password, the steps to recover your account are simple:

* Go to the [Forgot Password form](https://controld.com/forgot-password)
* Input the email you registered with
* Click the link in the email that we sent you, and reset your password to something you will not forget.
* We recommend using a password manager to prevent stuff like this from happening again. We recommend 1Password or Bitwarden.

## Lost 2FA

If you had 2FA on your account and you have lost access to the device that generates the one-time codes, you should use the recovery code you hopefully saved when you set up 2FA. The recovery code allows you to manually re-create the 2FA profile on your new device. Look for an option that says “Enter Code Manually” in the application you use to manage 2FA codes. 

If you did not store your recovery code, you should feel silly, then contact support and provide the following information:

* Your email address
* Date of when you first purchased Control D
* Method of payment used
* Any relevant transaction IDs that you have access to

## Lost Passkey

If you use [passkeys](doc:passkeys), try signing in with another enrolled passkey first. This could be another device, password manager, browser profile, or security key.

If **Passkey Enforced** is enabled on your account, resetting your password will not let you sign in with that password. You must sign in with a registered passkey, or contact support if you no longer have access to any enrolled passkeys.
